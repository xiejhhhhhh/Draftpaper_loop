## 发布前后的操作边界

在创建公开 release 前，应保持当前 release manifest、wheel 和工作流 Skill 不变；若代码继续修改，需重新运行本审计中的验证链并重新构建 wheel。创建 commit/tag/release 后，再将 tag、commit SHA、wheel SHA-256 和 GitHub Release URL 追加到本文件。该动作不应由 Agent 在没有明确用户授权时自动执行。
