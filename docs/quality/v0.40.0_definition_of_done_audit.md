## 设计边界

- `paper-fetch` 不承担主题发现。上游传入错误 DOI 时，它只能准确抓取错误论文，因此学科化 discovery 和抓取前门禁仍是第一道防线。
- Core 只默认解析候选身份，不默认下载全部全文；图片和补充材料默认关闭。
- 抓取成功不等于允许引用。只有 post-fetch 门禁通过且能从 active snapshot 到达的 work 才能进入摘要、引用池和 Agent 上下文。
- 明确声明的方法迁移或比较文献可以进入人工复核或 context-only 状态，但不能依靠跨学科共享词自动 active。
- provider 离线、限流、无全文或单篇失败只产生 degraded 证据，不覆盖上一份有效 snapshot。
- quarantine 操作采用 preview、packet hash、apply receipt 和 hash 校验 rollback；不会无审计地删除历史文件。
